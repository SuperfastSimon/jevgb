# Media

Screenshots rendered with headless Chrome. All dashboard data shown is **simulated** demo data.

| file | what |
| --- | --- |
| `dashboard.png` | dashboard, desktop, full page (simulated data) |
| `dashboard-brief-viewer.png` | handoff brief viewer dialog |
| `dashboard-mobile.png` | dashboard at 390 px width |
| `dashboard-empty.png` | empty state (no log loaded) |
| `landing.png` | landing page (`site/index.html`) |
| `logo-sheet.png` | logo variants, mark sizes, palette |
| `logo.png`, `mark-512.png` | raster logo / mark |

The upstream demo video and screenshot are not copied here. See
https://github.com/Bodila51/grok-bot-jev/tree/main/media.
